# City Languages - Toronto

## [Toronto's Linguistic Heritage](https://schoolofcities.github.io/city-languages/toronto)

**Authors:** [Aniket Kali](https://www.linkedin.com/in/aniket-k-8a8b9921b/), [Jeff Allen](https://jamaps.github.io/)

Analysis and visualization of first-language speakers across Toronto and surrounding municipalities. This project examines how linguistic communities have settled and changed over time using Canadian census data from 1971, 1996, and 2021.

### Data

Processed data and code are available in this repository.
